# {{inbox}}

Drop new files here when you do not know where they belong. Archives, PDFs, spreadsheets, screenshots, exports, anything.

This folder is normally empty. It is a queue, not a store.

## What happens to what you drop here

The next session that sees something here will:

1. Read it, and say what it is.
2. Check whether it already exists in the workspace. Duplicates turn up more often than expected.
3. Write an index document in the right project folder under `{{work_folder}}/`, with what the material is and what it means for the work.
4. Move the raw files to where they belong.
5. Add a `source` line to `{{work_folder}}/log.md`.
6. Leave this folder empty.

Nothing is deleted unless you have said yes.

## Why

Without a place like this, new files stay in the root, or land in a project folder with nothing that says what they are. Then they have to be read again every time. The index document means the material is read properly once, and what matters is written down.
