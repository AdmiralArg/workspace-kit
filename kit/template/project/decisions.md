# [Project name], decisions

Decisions that are hard to reverse, would surprise a colleague who joins later, or involve a real trade-off. Newest last. A decision is never rewritten: when it changes, add a new one and mark the old one as superseded.

Format for each decision:

    ### [Short title]
    [YYYY-MM-DD], status: accepted

    [What was decided, what it was chosen against, and why.]

The status is `accepted`, `proposed`, or `superseded by [title]`. An agent that meets work in conflict with an accepted decision stops and says so.
